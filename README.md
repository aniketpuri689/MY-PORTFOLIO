# MY-PORTFOLIO

🚀 **Personal Portfolio & Engineering Manifesto** — Showcasing production AI/ML projects, autonomous agentic systems, edge computer vision, and reactive Next.js full-stack architecture.

Built by **Aniket Puri** — Computer Science & Engineering (AI/ML) at GLA University.

---

## ⚡ Highlights & Features

- **3D Neural Particle Face & Orb Simulation**: High-performance HTML5 Canvas procedural particle engine with immediate Frame-0 rendering and real photo crossfade.
- **Hardware-Accelerated 60-120 FPS**: Zero layout thrashing, native scroll progress, and IntersectionObserver-optimized canvases.
- **Interactive Developer CLI (`AniketCLI`)**: Interactive cyber terminal with sound synthesis and rapid command navigation.
- **Tactile Custom Pointer**: Low-latency hardware-accelerated cursor ring and dot physics without main-thread blocking.
- **Architectural Lifecycle Playground**: Interactive interactive system visualizer tracking frontend hydration, OpenCV/ML inference, async ASGI backend transport, and autonomous agent loops.
- **Audio Synthesizer Atmosphere**: Built-in Web Audio API sub-bass drone and harmonic warm frequencies.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org) (App Router, Turbopack)
- **Library**: [React 19](https://react.dev)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com)
- **Animation & Physics**: HTML5 Canvas, GSAP, CSS Hardware-Accelerated 3D Transforms
- **Icons**: [Lucide React](https://lucide.dev)
- **Language**: [TypeScript](https://www.typescriptlang.org)

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/aniketpuri689/MY-PORTFOLIO.git
cd MY-PORTFOLIO
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the portfolio.

---

## 🌐 Deploy to Vercel

1. Push your latest code to your GitHub repository: `https://github.com/aniketpuri689/MY-PORTFOLIO`.
2. Go to [Vercel Dashboard](https://vercel.com/dashboard) and click **"Add New Project"**.
3. Import the `MY-PORTFOLIO` repository.
4. Leave the default settings (Next.js is automatically detected) and click **"Deploy"**.
5. Your portfolio is live with instant edge CDN delivery!
